# API Project

This project uses the JSONPlaceholder REST API to retrieve
employee information and TODO tasks.

## Requirements

- Python 3
- urllib
- json
- JSONPlaceholder API

## Tasks

### 0. Gather data from an API

Displays an employee's TODO progress and completed tasks.

Usage:

    python3 api/0-gather_data_from_an_API.py EMPLOYEE_ID

### 1. Export to CSV

Exports all TODO tasks belonging to an employee into a CSV file.

Usage:

    python3 api/1-export_to_CSV.py EMPLOYEE_ID

### 2. Export to JSON

Exports all TODO tasks belonging to an employee into a JSON file.

Usage:

    python3 api/2-export_to_JSON.py EMPLOYEE_ID

### 3. Dictionary of list of dictionaries

Exports all employees' TODO tasks into a JSON file.

Usage:

    python3 api/3-dictionary_of_list_of_dictionaries.py
## API

- https://jsonplaceholder.typicode.com/users
- https://jsonplaceholder.typicode.com/todos
